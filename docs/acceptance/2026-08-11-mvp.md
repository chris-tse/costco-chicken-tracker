`bun run acceptance:container` is the repeatable assembled gate. It builds the OCI image,
starts a disposable PostgreSQL 17 container, runs migration/startup/health checks, and invokes
`scripts/acceptance-journey.mjs` against the running image. It seeds one deterministic historical
record with an old creation instant, then runs axe, semantic and target checks, Tab/Shift+Tab/
Enter/Space keyboard checks, focus checks, horizontal-overflow checks, and the full Capture/Completion/
Correction/Recent/Plan journey at 375px, 390px, and 430px portrait widths. It also reloads before
enrichment and intercepts the doneness request to prove a failed enrichment leaves the created
sighting recoverable and correctable.

The `supported-chrome` CI job invoked that same resettable container gate separately with current
Chrome for Testing and with the immediately previous Chrome major. Both passed in CI run 31520253627.
