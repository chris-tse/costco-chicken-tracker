`bun run acceptance:container` is the repeatable assembled gate. It builds the OCI image,
starts a disposable PostgreSQL 17 container, runs migration/startup/health checks, and invokes
`scripts/acceptance-journey.mjs` against the running image. It seeds one deterministic historical
record with an old creation instant, then runs axe, semantic and target checks, Tab/Shift+Tab/
Enter/Space keyboard checks, focus checks, horizontal-overflow checks, and the full Capture/Completion/
Correction/Recent/Plan journey at 375px, 390px, and 430px portrait widths. Every viewport runs the
complete journey with distinct fixture records. The exact doneness-update request for the fixture
identity is intercepted to prove a failed enrichment leaves the created sighting recoverable and
correctable. The state-specific accessibility, target, and overflow checks include deletion
confirmation, post-correction completion, enrichment failure, and post-failure correction.

The `supported-chrome` CI job invokes that same resettable container gate separately with Chrome
for Testing `stable` and the prior major resolved at execution time. Those labels mean
time-of-run evidence, not a claim that a recorded dynamic version remains current later. The job
captures each resolved version in the raw acceptance log artifact.
